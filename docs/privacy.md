# QPARK Shot for Windows — Privacy Policy

Last updated: September 25, 2026.

QPARK Shot captures, edits and organizes screenshots locally on your Windows PC. No account is required. The application has no advertising, analytics or tracking SDKs and does not send screenshots, recognized text, preferences or usage data to the developer.

## Data on your device

Screenshots, optional recognized text, tags, favorites and preferences are stored locally. Text recognition uses Windows OCR on your device and requires installed recognition language components. Screen capture accesses the screen content you choose to capture. File access is used to open and save images in the default Pictures folder or folders you select.

Copying places the selected image on the system clipboard. Sharing occurs only when you choose Windows Share and a destination; the chosen service handles the image under its own privacy policy. Website and email links open external applications. Microsoft Store handles application delivery and updates under Microsoft's policies.

## Your controls

You can disable OCR and configure file storage and optional cleanup. Saved images removed by the application are sent to the Recycle Bin; app-owned temporary capture files can be deleted permanently. Uninstalling does not necessarily remove exported images or all local data. Editing drafts are kept for the running session.

## Support

Information you voluntarily send to work@qpark.io is used to respond to your request. Avoid including personal or sensitive screenshots unless needed for support. Contact work@qpark.io with privacy questions.

# Конфиденциальность QPARK Shot для Windows

Обновлено 25 сентября 2026 года.

QPARK Shot делает, редактирует и хранит снимки локально на вашем Windows ПК. Аккаунт не нужен. В приложении нет рекламы, аналитики и отслеживания. Снимки, распознанный текст, настройки и сведения об использовании не отправляются разработчику.

Снимки, результаты OCR, теги, избранное и настройки хранятся на устройстве. Распознавание текста выполняет Windows OCR локально; для него нужны установленные языковые компоненты. Приложение получает содержимое выбранной для снимка области экрана и обращается к файлам для открытия и сохранения изображений.

Копирование помещает изображение в системный буфер обмена. Отправка выполняется только по вашему действию через Windows Share; выбранный сервис обрабатывает изображение по своей политике. Ссылки на сайт и почту открывают внешние приложения. Доставку и обновления приложения через Microsoft Store регулируют правила Microsoft.

OCR можно отключить. Папки сохранения и автоматическая очистка настраиваются. Сохранённые изображения удаляются в Корзину; временные файлы приложения могут удаляться окончательно. После удаления приложения экспортированные изображения и часть локальных данных могут сохраниться. Черновики редактирования хранятся в течение текущего сеанса.

Сведения, которые вы сами отправляете на work@qpark.io, используются для ответа на обращение. По возможности исключайте личные и чувствительные данные из снимков для поддержки. Вопросы о конфиденциальности: work@qpark.io.
