# QPARK Shot 1.2.0 for Windows

## Download and install

- **Standalone installer:** download `QPARKShot-Setup-1.2.0.exe` from this release. It installs for the current user and includes .NET; no administrator access or separate runtime download is needed.
- **Microsoft Store:** [Get QPARK Shot](https://apps.microsoft.com/detail/9NVF4TS6Z0C7) for local Windows OCR and Store-managed installation and updates.
- Windows 10 version 1809 or later, or Windows 11, **x64**.

The standalone EXE is unsigned. Windows may display an unknown-publisher or SmartScreen warning. The Microsoft Store version is the signed installation option. The standalone installer does not install test certificates or change Windows security settings.

Windows OCR needs package identity and installed Windows OCR language components, so text recognition is available in the Store version. Filename and tag search, capture, editing, exports and the local library work in the standalone version.

## What's new since 1.1

- Library, Current Session, Favorites, Recent and Missing views, tags, search and relinking moved images.
- Independent editing drafts for multiple captures; crop and annotation undo/redo.
- Numbered callouts, opaque redaction, blur and a review view.
- Consistent PNG export, clipboard, pinned windows and Windows Share; clean, watermarked and support presets.
- Local OCR and recognized-text search in the Store version.
- Updated branding, light/dark/system themes and 12 core interface languages, including Russian and Arabic. Some Windows-specific messages use English or Russian fallback.
- Safer capture cancellation, cleanup, settings recovery and JSON backups.

## Updating from the GitHub 1.1 installer

Save any current captures, then quit QPARK Shot from the tray menu before running the new installer. Closing the main window alone leaves the app running in the tray. The installer reuses the existing install directory and retains settings and saved images. Uninstalling 1.2 preserves user files, including images placed inside the install folder.

Session drafts remain in memory until saved; save them before quitting. The standalone and Store installations are separate installations. Installing the Store version does not automatically remove the previous EXE installation.

## Integrity and source

`SHA256SUMS.txt` contains the installer SHA-256. In PowerShell, use `Get-FileHash .\QPARKShot-Setup-1.2.0.exe -Algorithm SHA256` and compare the result before installation.

Source archives are available below. Build and packaging instructions are in the repository README and `docs/msix.md`. The source tag identifies this release; the Store build provenance is recorded in `docs/microsoft-store.md`.

Screenshots and settings stay on the PC. No account, ads or external OCR service. Support: [work@qpark.io](mailto:work@qpark.io).

## Установка на русском

Скачайте **QPARKShot-Setup-1.2.0.exe**. Закройте приложение через пункт выхода в трее, предварительно сохранив снимки. Установщик обновит версию 1.1 в её текущей папке; настройки и изображения сохранятся. Требуется Windows 10 1809 или новее, x64. .NET уже включён.

EXE не имеет цифровой подписи, поэтому Windows может показать предупреждение об издателе. Для подписанной установки, автоматических обновлений и распознавания текста используйте [версию Microsoft Store](https://apps.microsoft.com/detail/9NVF4TS6Z0C7). В обычной EXE-версии доступны редактор, библиотека, теги и поиск по именам; OCR требует Store-версии.
