# QPARK Shot for Windows — Support

Email: **work@qpark.io**.

Include the application version, Windows version, steps to reproduce and the error message. Remove private information from screenshots before sending them.

- **Capture:** open the capture menu or configure shortcuts in Settings. If another app uses a shortcut, choose a different combination. Closing the main window leaves the application in the system tray; use Quit to exit.
- **OCR:** use the Microsoft Store/MSIX version. Install the required Windows OCR language components in Windows Settings, select recognition languages in the app's Library Index settings, then retry recognition. OCR runs locally.
- **Saving:** select a writable folder in Settings → Storage. Check whether external drives or network folders are accessible. Existing PNG files are not overwritten.
- **Missing images:** use Locate to reconnect a moved image and retain its favorites/tags. Do not delete the library index or reset preferences as a first troubleshooting step.
- **Cleanup:** automatic cleanup is optional. Saved files selected for removal go to the Recycle Bin. Active captures and favorites are protected from scheduled cleanup.

Windows 10 version 1809 or later, x64, is required. The MSIX includes the .NET runtime.
